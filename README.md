# lee4family-policies

Lee4Family 게임들의 개인정보처리방침과 플레이 안내 페이지. GitHub Pages 로 공개된다: https://jeddli.github.io/lee4family-policies/

- 게임 하나 = 폴더 하나 (`<slug>/index.md`). 루트 `index.md` 목록에 한 줄 추가.
- 본문은 JProject-HQ `Stores/PrivacyPolicy-template.md` 로 만든다. 게시 URL 은 HQ `Stores/README.md` 표에 적는다.
- 플레이 안내 = `<slug>/guide/index.html` + `img/`(정본은 그 게임 repo — 예: JProject04-Card `Docs/Guide`, 아티팩트 형식이라 올릴 때 doctype · head 를 붙인다). front matter 가 없는 HTML 이라 Jekyll 이 그대로 복사한다.
- 이 저장소는 공개다. 처리방침 · 플레이 안내 외의 것은 넣지 않는다.
